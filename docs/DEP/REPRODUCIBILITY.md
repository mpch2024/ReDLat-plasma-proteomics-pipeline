# Reproducibility specification

## Execution model

Each canonical script is run in a separate clean R process by the workflow runners. This prevents objects or packages left in an interactive session from altering later stages.

## Environment

The DEP module uses the repository-level `renv.lock`. Restore it before execution:

```r
renv::restore()
```

Scripts never install or update packages automatically. Every run records `sessionInfo()` through the analysis manifest generated by Script 01 and the downstream audit folders.

## Randomness

The original prespecified seeds are retained:

- primary and fixed-map analyses: `1234`;
- matched sensitivity: `20260519`;
- other seeds remain defined within their originating scripts.

Randomized analyses must not be rerun with a different seed for the manuscript release.

## Canonical inputs

The only raw inputs are configured locally:

- harmonized clinical metadata CSV;
- SOMAscan ADAT file.

No script searches a user desktop, cloud-synced folder or historical project directory. The configuration file selects exactly one input of each type.

## Canonical outputs

- `result/`: private intermediate and analytical outputs;
- `publication_candidate/DEP/`: Source Data, Supplementary Data and figures awaiting privacy and consistency review.

Neither output directory is tracked by Git.

## Fixed interpretation universe

The release enforces 9,638 unique `EntrezGeneSymbol–AptName` pairs inherited from the primary `DEP_gene` table. Sensitivity and recruitment-context analyses are not permitted to reselect a different SOMAmer for a gene.

## Validation before release

Run:

```bash
Rscript --vanilla workflow/audit_dep_repository.R
Rscript --vanilla workflow/audit_publication_candidate.R
```

The second audit is necessary but not sufficient: a human review of every workbook remains required before journal submission or archival deposition.
