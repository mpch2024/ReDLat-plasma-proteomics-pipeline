# Output classification

| Output | Location | Classification | Public by default? |
|---|---|---|---|
| Harmonized participant matrix | `result/` workspace | Restricted | No |
| Sample IDs and analytic participant sets | `result/private/participant_sets/` | Restricted | No |
| PCA matrices and identifier-bearing scores | `result/private/pca/` | Restricted | No |
| Protein-level model results | `result/` | Controlled analysis output | No |
| Aggregate summaries and pathway results | `result/` | Review required | No |
| Source Data workbooks | `publication_candidate/DEP/source_data/` | Release candidate | No |
| Supplementary Tables/Data | `publication_candidate/DEP/` | Release candidate | No |
| Main and Extended Data figures | `publication_candidate/DEP/figures/` | Release candidate | No |

Nothing moves from a release candidate to GitHub or Zenodo automatically.
