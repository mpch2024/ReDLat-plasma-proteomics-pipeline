# R package requirements

The scripts use packages from CRAN and Bioconductor, including WGCNA, dynamicTreeCut, clusterProfiler, ReactomePA, org.Hs.eg.db, enrichplot, dplyr, tidyr, readr, tibble, purrr, stringr, ggplot2, patchwork, cowplot, ggraph, igraph, openxlsx, sandwich, lmtest, broom, metafor, svglite, pdftools, png, ggtext and zip.

The authoritative versions must be recorded in the repository-level `renv.lock`. Scripts do not install or update packages automatically.
